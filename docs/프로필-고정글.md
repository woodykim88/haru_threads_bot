# 프로필·고정 글 (2026-10-11)

Threads API로는 소개 문구와 고정 글을 바꿀 수 없어서 앱에서 직접 바꿔야 한다. 방문자가 팔로우를 정하는 곳이 여기다.

## 소개 문구 (150자 이내, 아래 중 하나)
1. `월~금 당근 회사 다니는 30대 직장인 토끼 🐰 퇴근만 기다리는 중 / 월 부엉이 부장 어록 · 화 다람쥐 동기 속보 · 수 퇴사 충동 지수 · 목 엄마 토끼 전화 · 금 칼퇴 카운트다운`
2. `잠 많고 당근 좋아하는 직장인 토끼 하루 🥕 이불 밖은 위험해 / 평일 16시 연재: 부엉이 부장 어록 외 4코너`

(요일 코너 이름은 `src/persona.py`의 CORNERS와 같다. 코너를 바꾸면 소개 문구도 바꾼다.)

## 고정 글 후보
조회 상위 글 중 "친구들에게 소개하기 좋은" 글을 고정한다. 새로 쓴다면:

> 다람쥐 동기가 "너 퇴근 후에 뭐 해?" 물어서 "이불이랑 데이트"라고 했어 🐰
> 여긴 당근 회사 다니는 30대 직장인 토끼 하루의 일기장이야.
> 월 부엉이 부장 어록 / 화 다람쥐 동기 속보 / 수 퇴사 충동 지수 / 목 엄마 토끼 전화 / 금 칼퇴 카운트다운
> 너는 어느 요일 코너가 제일 기대돼? ① 월 ② 수 ③ 금

- 대사로 시작하고, 코너 목록으로 팔로우할 이유를 주고, 한 글자로 답하는 질문으로 끝나는 구조다.
- 고정은 글 우측 상단 ··· 메뉴 → "프로필에 고정".
