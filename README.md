# Threads @rabbit.haru1130 자동 게시 (토끼 캐릭터 하루)

잠 많고 당근 좋아하는 20대 감성 토끼 "하루"의 일상·공감 글을 하루 5번(09:00, 12:30, 16:00, 20:00, 23:30) Threads에 올리는 가상 인플루언서 실험 채널입니다.

- 뉴스·제품·링크 없음. 20:00 글에는 프로필 그림(assets/haru_ref.jpg)을 기준으로 그린 하루 그림 1장을 붙입니다 (src/image.py, gpt-image-2, R2 threads-haru/). 그림이 실패하면 글만 올립니다. 시간대별 분위기(src/channel.py MOODS)와 형식(src/persona.py SLOT_FORMATS)을 돌려 가며 씁니다.
- AI 표시는 하지 않는 대신, 하루는 끝까지 토끼 캐릭터로만 말합니다. 실제 사람처럼 보이는 표현(20대 여자, 남친, 출근길 등)은 검수에서 막습니다 (src/persona.py).
- 검수에 두 번 떨어지면 준비된 캐릭터 글로 올립니다 (회차를 건너뛰지 않음, 텔레그램에 ⚠️).
- 댓글 자동 답글: 2시간마다 새 댓글에 하루 말투로 답합니다 (src/replies.py, 한 번 5개·하루 20개 한도, 욕설·스팸·"AI야?" 같은 정체 질문은 건너뜀).
- 성과 반영: 매일 조회수 상위·하위 글을 글쓰기 참고로 넣습니다 (src/performance.py, AI 호출 없음).
- 텔레그램: 같은 봇, `[Threads 하루]`, 명령 `/haru_stop` `/haru_skip` `/haru_resume`
- 2026-10-03 성과 반영 (25편, 시각별 조회수 중앙값 09:00 183 · 16:00 188 · 23:30 99 · 12:30 31 · 20:00 12, 질문 있는 글 126.5 vs 없는 글 83):
  - 20:00: 질문 없는 위로·일기 → "이거 나만 그래?" 퇴근 후 구체적 장면 + 마지막 줄 한 줄 질문. 그림은 그대로 20:00. 한 주 뒤에도 20:00이 약하면 다음 실험은 그림을 09:00이나 16:00으로 옮기기.
  - 12:30: 빈칸 채우기·체크리스트·밸런스 게임(A/B)·유형 테스트 중단 → 조연(다람쥐 동기·부엉이 부장, 주말엔 봄이·엄마 토끼)이 나오는 점심 장면 + 마지막 줄 한 줄 질문. 준비된 글도 같은 형식 (src/persona.py SLOT_FALLBACKS).
  - 12:30·20:00은 마지막 줄에 물음표가 없으면 검수에서 다시 씁니다 (ENDS_WITH_QUESTION). 주말 형식의 빈칸 채우기도 "이거 나만 그래?" 주말 공감으로 바꿨습니다.
  - 공유 줄: 16:00·23:30 글에 하루 걸러 "공감되면 리포스트 🔁" 같은 태그·리포스트 한 줄을 코드가 붙입니다 (SHARE_SLOTS·SHARE_EVERY·SHARE_LINES, 날짜 기준으로 하루 한 번 두 시각을 번갈아). 마지막 줄이 질문이면 그 앞에 넣어 질문으로 끝나게 합니다. "~하면 ~해 줄게" 같은 조건부 부탁은 Meta가 도달을 줄여서 검수에서 막습니다.
- 정시 실행: `~/Projects/인스타피드 건강뉴스 자동화/scheduler` (Cloudflare 정시 알람). GitHub cron은 예비.

```
python -m pytest -q
python -m src.main --job preview              # 오늘 5개 시간대 글 미리보기 (게시 안 함)
python -m src.main --job preview --slot 23:30 # 한 시간대만
```

- 2026-10-10 개편 (팔로워 6~15명, 글당 조회 중앙값 50~120회): 첫 글에 토픽 태그 1개를 붙인다 (`TOPIC_TAG`, `src/threads.py`). 태그 때문에 거절되면 태그 없이 다시 만든다.
- 2026-10-10: 20:00 그림을 껐다 (`channel.IMAGE_TIMES = ()`). 그림을 붙인 20:00 글 5편이 조회 21~40회였고, 같은 기간 글만 올린 글은 중앙값 약 120회였다. 다시 켜려면 `('20:00',)`.

- 2026-10-11 반응 개선 (조회는 8~242회로 나오는데 좋아요·댓글은 거의 0, 팔로워 15명 안팎):
  - 하루 4번으로 축소 (09:00·12:30·16:00·23:30). 20:00은 조회 중앙값 35로 5개 시각 중 가장 낮아 뺐다. GitHub 변수 `PUBLISH_TIMES`도 같이 바꿔야 적용된다. 되돌리려면 변수에 20:00을 다시 넣는다.
  - 첫 문장 훅: 시간·요일·장소로 시작하면 검수에서 다시 쓴다 (`persona.FLAT_OPENING`). 조회 8~14회 글은 전부 "오후 4시에…", "목요일 아침…"으로 시작했다.
  - 평일 16:00 요일 코너 연재 (`persona.CORNERS`): 월 부엉이 부장 어록 · 화 다람쥐 동기 속보 · 수 오늘의 퇴사 충동 지수 · 목 엄마 토끼 전화 어록 · 금 칼퇴 카운트다운. 글이 코너 이름으로 시작해야 통과. 쉬는 날은 주말 형식.
  - 선택형 질문: 12:30 조연 장면과 23:30 속마음+질문은 마지막 줄이 "① … ② …?"·"A vs B?"여야 통과 (`persona.CHOICE_FORMATS`).
  - 남의 글 댓글 초안: `data/outreach_inbox.md`에 글을 붙이고 `python -m src.main --job outreach` → `output/outreach_drafts.md`. 게시는 사람이 직접 한다 (API 권한 없음, 긁어 오기 금지).
  - 프로필 소개 문구·고정 글 후보는 `docs/프로필-고정글.md` (앱에서 직접 바꿔야 함).
  - 효과 확인: 1주 뒤(10/18) 날짜별 조회 중앙값과 좋아요·댓글 수를 10/10 이전과 비교. 코너·선택형이 효과 없으면 되돌린다.
